# Runtime data

The hourly GitHub workflow creates and updates the live JSON files in this folder.

For an existing repository, keep your current live files:

- signals_latest.json
- signal_history.json
- paper_trades.json
- external_calls.json
- external_inbox.json
- external_seen.json
- external_monitor_status.json

The `templates` folder is used only for a brand-new repository. Uploading V8 over the
existing project does not require replacing your accumulated runtime JSON files.
