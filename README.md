# Crypto Intelligence Terminal V12.0.0 — Smart Desk

V12 follows one rule: **simple front, smarter brain**.

The visible interface is reduced to decision-useful information. The engine gains a new
evidence-based learning layer that studies entries, exits, process quality, missed re-entry,
book expectancy and committee conditions.

Learning is deliberately sample-gated. A single successful chart cannot rewrite the system.
Candidate lessons need repeated examples, promoted lessons need a larger sample, and no rule
is ever changed automatically.
